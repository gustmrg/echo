# Echo

**A free, open source, offline speech-to-text app — a soft fork of [Handy](https://github.com/cjpais/Handy).**

Echo is a cross-platform desktop application for simple, privacy-focused speech transcription. Press a shortcut, speak, and have your words appear in any text field — all processed on your own computer, never in the cloud.

## Provenance

Echo tracks upstream Handy and stays as close to it as possible. All transcription, audio, and platform integration work is inherited from Handy; Echo differs only in branding and a small set of additional features.

Handy's code is MIT-licensed (see [LICENSE](LICENSE)); the Handy name, logo, and brand assets are **not** open source, so Echo ships its own branding as required by upstream's license terms. All credit for the underlying application goes to [cjpais](https://github.com/cjpais) and Handy's contributors.
